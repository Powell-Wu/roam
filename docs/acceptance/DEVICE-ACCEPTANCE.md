1. 在线首次打开，点击“直接试玩”，记录从页面打开到看见第一张任务的秒数。完成首卡，选择方向，刷新后核对方向和卡片。完成三卡、填写一句回忆、保存并下载纪念票。
2. 在正式短途里左滑换卡、右滑完成；短拖回弹、纵向滚动、触摸取消不应提交。暂停后不能滑牌，继续后可用；撤销恢复任务和积分。
3. 使用按钮及系统减少动态效果设置完成任务。检查小屏横向溢出、顶部安全区、底部导航和输入时的软键盘；长任务在详情可完整读取。
4. 任务花费输入未提交时切后台、锁屏、刷新。回到同一张卡时保留输入。更换卡片后不得带入旧卡花费；收尾文字刷新后保留。
5. 等待“离线内容已准备好”，退出再断网打开，抽卡、完成、收尾、刷新和查看历史。首次准备中断时重新联网并重试；不能把尚未就绪写成离线成功。
6. 旧版保存测试行程和花费草稿，另开旧标签；部署新版后手动检查并应用更新。核对输入、行程 ID、旧积分。旧标签不应被强制刷新；新页提示关闭或更新旧标签时照提示操作，再继续。不要导入 v2 给原 v1 客户端。
7. 在设置开启声音，试听翻牌、盖章、达档。切后台或锁屏时停止，前台下一次操作可恢复；关闭后保持安静。确认保存图片的下载/分享入口在该手机可用。
8. iPhone 开启 VoiceOver，Android 开启 TalkBack，分别用按钮完成抽卡、理解任务、完成、暂停/继续和收尾。记录控件名称、焦点顺序、状态反馈是否可读，以及弹窗关闭后的焦点；不能以桌面键盘或减少动态效果的检查代替屏幕阅读器结果。
9. 第二轮分别选择观察城市和默契挑战：读开场提示、完成一局、回答收尾问题并保存纪念票。两人比较任务组合和合作方式是否不同；第二局记录重复卡、换卡原因及是否愿意再玩。主题须使用已包含第二轮的实际版本。
